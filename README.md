# Silvia Pizzeria

A production-ready single-page restaurant website built with Vite, React, and Tailwind CSS.

## Features

- Modern mobile-first design
- Warm Italian color palette
- Menu filtering by category
- Smooth scrolling navigation
- WhatsApp order links with pre-filled messages
- Google Maps embed for location
- Responsive menu layout on mobile, tablet, and desktop

## Tech Stack

- Vite
- React
- Tailwind CSS
- Lucide icons

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

Open the local address shown in the terminal.

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Replaceable assets

- `src/App.jsx` uses Unsplash placeholder images for the hero section.
- Replace the `img` src URL with local assets or your own hosted images.

## Notes

- WhatsApp number is configured for `212776768251`.
- Hours in the UI are Tuesday–Sunday 12:00 PM – 12:00 AM, closed Monday.
- Menu data is hardcoded in `src/menuData.js`.
